# ParkSmart

A student Android application developed as a B.Tech final year project to help drivers find and manage parking spaces more efficiently. The app is built with Java and the Android SDK, uses Firebase for backend services, and is packaged as a Gradle Android application module.

## Key features
- Search for nearby parking spots (map or list)
- View parking spot details (availability, price, distance)
- Book or reserve a parking slot (demo / local flow — replace with backend if available)
- User authentication via Firebase (email / Google)
- Local caching of recent searches and preferences
- Release build configured with ProGuard/R8 rules

## Tech stack
- Language: Java
- Platform: Android (SDK, Gradle)
- Build system: Gradle (gradlew wrapper included)
- Backend services: Firebase (google-services.json included)
- Release/Obfuscation: ProGuard / R8 (proguard-rules.pro)
